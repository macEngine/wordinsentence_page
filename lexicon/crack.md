## 常用义

1. **v. 裂开、破裂**（东西"咔"地裂了）— the ice cracked / crack an egg
2. **v. 撑不住、崩溃**（人或经济在压力下垮掉，本文用法）— the consumer finally cracks / crack under pressure
3. **v. 破解、攻克**（难题、密码、市场）— crack the code / crack the case
4. **n. 裂缝；一次尝试** — a crack in the wall / have a crack at it

## 一眼记住

- 💥 **crack 是"咔"的一声** 古英语拟声词；东西裂开的声音，引申为"裂开 → 垮掉"。
- 🥚 **鸡蛋先裂再碎** 裂缝（crack）是垮掉（crash）之前的那一声——所以 crack 常指"快撑不住了"。
- 🔓 **crack the code = 把密码敲开** 攻克难题也是"敲开一条缝"。

## 短语

- **crack under pressure** 在压力下崩溃
- **crack down on** … 严厉打击……
- **crack the code / case** 破解密码 / 破案
- **have a crack at** … 试一把……
